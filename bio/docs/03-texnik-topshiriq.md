# 3. Texnik topshiriq (MVP)

## Funksional talablar
- F1. Turlar ro'yxati va qidiruv (nom, lotincha nom bo'yicha).
- F2. Tur sahifasi: taksonomiya, tavsif, saqlanish holati, manba.
- F3. Ikki turni yonma-yon taqqoslash.
- F4. Manbali savol-javob (bazadan qidiruv, LLMsiz).
- F5. Admin: tur qo'shish/tahrirlash (2-versiyada).

## Nofunksional talablar
- Mobil qurilmada qulay (responsive).
- Sahifa 2 soniyadan tez ochiladi.
- Har bir faktda manba maydoni majburiy.
- Foydalanuvchi shaxsiy ma'lumoti yig'ilmaydi (MVPda login yo'q).

## Texnologiya (bepul)
Python 3, Flask, SQLite, HTML/CSS. Hosting: PythonAnywhere yoki Render bepul tarifi (shartlarini tekshiring).

## Qabul mezoni
Yangi tur bazaga qo'shilsa, kod o'zgarmasdan saytda ko'rinadi, qidiruv va savol-javobda ishlaydi.
