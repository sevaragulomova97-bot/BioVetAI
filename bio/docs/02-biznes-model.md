# 2. Biznes model

## Bosqichlar
**Bosqich A (0–6 oy): bepul, auditoriya yig'ish.** Daromad yo'q, maqsad — foydalanuvchi va kontent.

**Bosqich B (6–18 oy): daromad manbalari (sinab ko'riladi):**
1. **Maktab/litsey obunasi** — o'qituvchi paneli, test va topshiriqlar.
2. **Premium** — kengaytirilgan taqqoslash, PDF konspekt, reklamasiz.
3. **Grantlar** — ta'lim va tabiatni asrash fondlari.
4. **Hamkorlik** — muzey, zoopark, qo'riqxonalar bilan kontent.

## Xarajatlar
Boshida: domen (yiliga bir necha dollar), bepul hosting. Keyin: server, AI API, kontent muharriri.

## Taxminlar (tekshirilishi shart)
Narx va to'lovga tayyorlik hozircha taxmin. 10–15 o'qituvchi bilan intervyu o'tkazib tasdiqlang.
