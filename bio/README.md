# BIO-LAB AI

Hayvonot olami bilimlarini manbasi bilan birlashtiruvchi raqamli biologik laboratoriya.

## Ishga tushirish (bepul, 3 qadam)
1. `pip install flask`
2. `cd app`
3. `python app.py`  →  brauzerda http://127.0.0.1:5000

## Papkalar
- `docs/` — 1–8 va 10-bandlar (konsepsiya, biznes model, texnik topshiriq, sahifalar, database, AI, dizayn, MVP reja, strategiya)
- `app/` — 9-band: birinchi ishlaydigan platforma (Flask + SQLite + HTML/CSS)

## Muhim eslatma
`app/app.py` dagi 10 ta tur ma'lumoti **boshlang'ich namunadir**. IUCN holatlari o'zgarib turadi:
har bir tur uchun https://www.iucnredlist.org dan qayta tekshiring.
